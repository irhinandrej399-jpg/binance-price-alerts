# MKT-002 — Источник цены Binance Spot

Дата: 27 октября 2026. Статус: принято в рамках [MKT-002](../backlog/tickets/MKT-002.md).

DEC-002 оставил выбор `trade`/`aggTrade` этому тикету; его критерий прямо поручает
выбрать один источник последней сделки. Это инженерный выбор в разрешённом объёме,
без изменения продуктовой семантики цены.

Рассмотрены raw `trade` (отдельная сделка, ID `t`) и `aggTrade` (агрегация для одного
taker order, ID `a`). Выбран raw `trade`: прямая идентичность отдельной сделки и её
цены позволяет не вводить дополнительную семантику агрегата. Транспортный формат
проверен по [Binance WebSocket Streams](https://github.com/binance/binance-spot-api-docs/blob/master/web-socket-streams.md#trade-streams).

Логический источник — `binance-spot-trade`, не ID соединения. SourceID — строковое
представление целого `t` без float; его область уникальности — поток и пара.
Время сделки берётся только из `T`, время события — из `E`. Единицы задаёт
вызывающий код явно, приём не меняет биржевые времена.

[Чистый адаптер](../../internal/marketdata/trade/README.md) принимает только raw
trade. MKT-009 должен подписываться на `<symbol>@trade` и передавать корректные
единицы времени; при combined transport он сначала извлекает raw data.
MKT-005/MKT-017 отвечают за порядок и durable ревизии. Смена вида потока позднее
требует явной миграции идентичности по CON-003. Сетевые соединения, восстановление
истории, назначение ревизий и оценка производительности в этот выбор не входят.
