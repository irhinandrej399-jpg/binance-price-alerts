## Контракт типа

- Пакет `internal/domain/price`: неизменяемый `Price`, `Parse(string) (Price, error)`, `String() string`, `Cmp(Price) int`, text/JSON marshal/unmarshal.
- Диапазон: 0 … 999999999999999999.999999999999999999 включительно; максимум 18 значащих цифр целой части и 18 входных цифр после точки. Ноль допустим на уровне типа; требования положительности конкретной операции задаются её валидацией.
- Формат входа: ASCII-цифры, необязательная точка с непустой дробью. Знак, пробелы, экспонента, запятая запрещены. Ведущие нули принимаются, лишняя дробная точность отклоняется даже при нулевых хвостах; округления нет.
- Каноническая строка убирает ведущие нули целой части и конечные нули дроби; ноль — `0`. JSON содержит строку, числовые JSON-токены и null отклоняются. Ошибка unmarshal не меняет прежнее значение.
- `ErrFormat` отделяет неверный синтаксис от `ErrRange` (диапазон/точность). Нулевое значение Go соответствует цене 0; сравнение точное, без float и внешних зависимостей.
- Хранилище и процентная арифметика сюда не входят; будущая SQL-схема должна сохранять этот диапазон (например, NUMERIC(36,18)) и не округлять невалидный вход до доменной проверки.
