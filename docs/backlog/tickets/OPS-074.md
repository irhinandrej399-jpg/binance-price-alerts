# OPS-074 — Собрать постоянный запуск четырёх сервисов

Статус: `planned`. Приоритет определяется зависимостями, а не номером.

Зависимости: [DEC-011](DEC-011.md), [MKT-019](MKT-019.md), [E2E-002](E2E-002.md)

## Модель для сессии

- Модель: `gpt-6.1-sol`.
- Уровень размышления: `medium`.
- Обоснование: Один воспроизводимый deployment на готовых сервисах и хранилищах.

Рекомендация, не переключение модели. [Условия выбора](../MODELS.md).

## Один результат

Документированный запуск постоянного стенда одной командой из чистого checkout.

## Критерии приёмки

- Добавить сборку образов четырёх сервисов и Compose-профиль для одного хоста с PostgreSQL/Kafka, отдельным шагом миграций и init topics. Использовать постоянные volumes; restart не меняет ClusterID/TopicID или transactional IDs.
- Дать .env.example без секретов, проверку обязательных настроек и руководство start/status/stop/update. Стенд использует настоящие Binance/Telegram endpoints; тестовый режим явно отделён. Нужные сертификаты выдаются отдельной локальной командой для development; public ingress — OPS-075.
- Сохранять четыре отдельные БД/роли и mTLS identities. Runtime не запускается от migration owner; DSN, bot token и private keys не попадают в образ, Git, argv или вывод.
- Малый smoke через имеющиеся fake: старт, регистрация/подписка/цена/доставка, stop/start с теми же volumes и сохранённой подпиской. Не выполнять docker down -v для постоянного профиля. Проверить build/config/startup failure; без новых fault-proxy и capacity harness.

## Проверка

Только относящиеся к изменению unit/integration проверки, один небольшой smoke
на имеющихся средствах и обязательные проверки CI. Для поведения Red → Green;
для deployment/docs — проверка команд и фактического запуска, без искусственных
unit-тестов. Отсутствующую предпосылку не разрабатывать скрытно.

## Границы и сессионная проверка

Один хост, по одной реплике. Выдача публичного TLS, настройка домена и реальная доставка проверяются отдельно. Kubernetes, HA и benchmark не входят.

Перед ready сверить фактические интерфейсы и размер по [workflow](../workflow.md).
При независимых результатах разделить; новая рекомендация модели объём не заменяет.
