Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [CON-004](CON-004.md), [DOM-001](DOM-001.md)

## Модель для сессии

- Модель: `gpt-6-luna` (GPT-6 Luna).
- Уровень размышления: `high` (High).
- Обоснование: Одна чистая функция форматирования использует готовые значения; точность и escaping проверяются fixtures.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Чистая функция формирования одного сообщения.

## Критерии приёмки

- По [ADR DEC-004](../../decisions/DEC-004.md): передаваемая фактическая цена берётся из свежего допуска попытки, не из исторического AlertTriggered; при необходимости отображаются время сделки/предупреждения DEC-002.
- В тексте есть пара, порог, фактическая цена и направление; спецсимволы корректно обработаны.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

Рекомендация — GPT-6 Luna · High; настройки модели не менялись.
- Добавлены `internal/notifications/message/message.go`, `message_test.go`, `README.md`: `Format(Input)` возвращает русский HTML-текст с парой, включительным направлением, точным порогом и фактической ценой, временем UTC и точным возрастом. Цена и диагностика передаются из проверенной котировки допуска; историческое событие не является входом formatter. Caller отвечает за получение действующего допуска и его срок.
- Возраст > 5 с и unconfirmed/gap дают независимые предупреждения DEC-002 без TTL/отказа. Некорректные/будущие времена, отсутствующая фактическая цена, пустая пара и неизвестное направление возвращают ошибку без текста. Для отображения требуется `parse_mode=HTML`; правила экранирования сверены с официальным Telegram Bot API (ссылка в README).
- Red: `GOTOOLCHAIN=local go test ./internal/notifications/message` — FAIL, ожидаемая причина `no non-test Go files`: fixtures написаны до реализации. Green: `GOTOOLCHAIN=local go test -race ./internal/notifications/message -count=1` — PASS после реализации.
- Refactor: gofmt, отдельный расчёт возраста в секундах без насыщения time.Duration. Snapshot/табличные тесты покрывают оба направления, цены 18/18 и минимальный шаг, нормализацию, HTML-символы, 5 с и 5 с + 1 нс, независимые предупреждения, UTC, дробный возраст через границу секунды, большой возраст и ошибочный вход. Повторный race-прогон пакета после дополнения проверки дробного возраста — PASS.
- Итоговые общие проверки с `GOCACHE=/tmp/binance-ntf002-go-build GOMODCACHE=/tmp/binance-go-mod GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off`: `go test -race ./...`, `go vet ./...`, `go build ./...` — PASS. Для общего test разрешён запуск вне sandbox с loopback listeners. Первые прогоны упирались в системный cache, пустой отдельный modcache и запрет sandbox на bind; они не считались успешными.
