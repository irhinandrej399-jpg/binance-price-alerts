# SET-003 — Поднять локальное хранилище

Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [DEC-006](DEC-006.md), [DEC-008](DEC-008.md)

## Модель для сессии

- Модель: `gpt-6-luna` (GPT-6 Luna).
- Уровень размышления: `high` (High).
- Обоснование: После принятия ADR требуется воспроизводимая локальная конфигурация одной СУБД с healthcheck.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Команда запуска изолированного локального хранилища.

## Критерии приёмки

- По [DEC-008](../../decisions/DEC-008.md): PostgreSQL — 4 vCPU/10 GiB RAM, volume 120 GiB (80 обычная работа, 24 резерв завершения, 16 аварийный запас). Закрепить digest образа и настройки durability; меньший функциональный стенд явно отличается от нагрузочного. Ограничители и квалификация стоимости операций сюда не входят.

- По [DEC-006](../../decisions/DEC-006.md): PostgreSQL с четырьмя БД и изолированными runtime/migration-ролями; runtime не имеет DDL/административных прав. Проверить доступ к своей БД и отказ к каждой чужой под всеми четырьмя ролями. Постоянный volume и fsync/synchronous_commit/full_page_writes включены; unlogged-таблицы для принятой работы запрещены.

- Версия образа закреплена; есть healthcheck и инструкция остановки; секреты передаются конфигурацией.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

На чистом окружении хранилище становится доступным; остановка не удаляет данные без явной команды.
