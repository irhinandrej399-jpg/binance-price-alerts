## Один результат

Один endpoint создания подписки по цене либо проценту.

## Критерии приёмки

- По [ADR DEC-004](../../decisions/DEC-004.md): создание сохраняет active и занимает слот даже при true исходного условия; не завершает подписку по снимку. Дальнейшая проверка по последней цене не требует нового пересечения.
- Пара проверяется по каталогу; владелец берётся из сессии; порог и исходная котировка сохраняются; отсутствие допустимой котировки и превышение лимита имеют ошибки.
- По [ADR DEC-002](../../decisions/DEC-002.md) для обоих видов подписок используется последняя известная корректная котировка независимо от возраста. В ответе создания — исходная цена, время сделки, возраст и предупреждения: возраст > 5 секунд и известный разрыв/неподтверждённое состояние потока отмечаются отдельно. При stale, разрыве связи или сохранённой цене после рестарта создание успешно с предупреждением, без дополнительного подтверждения. При missing/invalid_time — HTTP 503, код quote_unavailable, без создания и расхода слота. Исходные цена и время сохраняются; предупреждения вычисляются при использовании котировки.
- По [DEC-005](../../decisions/DEC-005.md) нет привязки — HTTP 409 telegram_not_linked, без подписки, workflow, outbox и расхода слота. Проверка канала согласована с сохранением подписки при конкурентном изменении привязки.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Сценарии TDD (Red → Green → Refactor)

HTTP-тесты цены, процента, неизвестной пары, чужого user_id и 16-й подписки; для обоих видов — успех на границе 5 секунд и успех с предупреждением сразу после неё, для редкой пары и при старении до использования. Проверить расчёт +5% от старой цены 100 в порог 105; уже выполненное условие по старой цене; отдельное предупреждение о разрыве даже при молодой цене и после рестарта. При missing/invalid_time проверить 503 quote_unavailable и отсутствие подписки/расхода слота. Предупреждения возвращаются вместе с успешным созданием.

Дополнительно: без Telegram оба вида создания отклоняются без побочных записей даже при истинном условии; конкурентное изменение канала не обходит проверку.
