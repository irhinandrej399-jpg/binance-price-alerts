## Контракт HTTP

- `POST /v1/accounts`, `Content-Type: application/json` (допустим charset), единственный JSON-объект с `email` и `password`; неизвестные поля и второй JSON отклоняются.
- Email нормализуется интерфейсом IAM-001; принимается один bare addr-spec, без display name, пробелов и комментариев, с непустыми local/domain. Проверка принадлежности адреса не выполняется.
- Пароль — непустая строка, байты сохраняются точно по IAM-002; дополнительная политика сложности не вводится.
- 201: только `id` и нормализованный `email`; 400 `invalid_request`, 409 `email_exists`, 415 `unsupported_media_type`, 500 `internal_error`. Ошибки имеют вид `{"error":{"code":"..."}}`, без credentials и внутренних деталей. Другой метод — 405, другой путь — 404 через стандартный ServeMux.
- Результат — подключаемый `http.Handler`; runtime wiring cmd/api, лимит тела OPS-012 и распределённый rate limit OPS-013 не входят.
