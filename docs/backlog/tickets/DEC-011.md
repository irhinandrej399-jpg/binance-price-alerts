- Модель: `gpt-6.1-sol`.

- Обоснование: Ревизия плана по явному уточнению пользователя, без новой архитектуры.

Пересмотренный бэклог: production готовность малого deployment без
исследовательской и тяжёлой нагрузочной квалификации.

- Все 27 незавершённых карточек проверены по назначению и зависимостям;
