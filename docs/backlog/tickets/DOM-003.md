# DOM-003 — Реализовать предикат срабатывания

Статус: `planned`. Приоритет определяется зависимостями, а не номером.

Зависимости: [DOM-001](DOM-001.md), [DEC-001](DEC-001.md)

## Модель для сессии

- Модель: `gpt-6.1-sol` (GPT-6.1 Sol).
- Уровень размышления: `medium` (Medium).
- Обоснование: После закрытия DEC-001 остаётся один чистый предикат с конечным набором граничных сценариев.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Чистая функция проверки одного ценового условия.

## Критерии приёмки

- По [ADR DEC-004](../../decisions/DEC-004.md): true означает выполненный предикат последней переданной цены, а не безусловное позднее уведомление по цене создания.
- Поведение полностью совпадает с [ADR DEC-001](../../decisions/DEC-001.md): вход — текущая цена, порог и направление; `up` проверяет `P >= T`, `down` — `P <= T`. Предыдущая цена не требуется.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Сценарии TDD (Red → Green → Refactor)

При пороге 100: `up` для 99 — false, для 100 и 101 — true; `down` для 101 — false, для 100 и 99 — true. Проверить скачки 99→101 и 101→99, ложные условия 98→99 и 102→101 и первую цену без предыдущего значения. Равенство и уже выполненное условие при создании дают true; доставка требует повторной проверки последней цены по DEC-004; исходный true не фиксирует необратимый результат.

## Не входит

Поиск подписок в индексе.

## Размер сессии

Оценка: **кандидат на одну сессию после закрытия зависимостей**, не подтверждённый `ready`.
Для старта нужны только эта карточка, применимые ADR, готовые интерфейсы из зависимостей и относящийся к поведению код. Если требуется выбрать протокол, реализовать недостающую зависимость или менять независимое поведение, карточка сначала уточняется либо делится по [сессионной проверке](../workflow.md#сессионная-проверка-перед-ready).
