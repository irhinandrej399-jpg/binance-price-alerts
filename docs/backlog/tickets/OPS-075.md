# OPS-075 — Защитить публичный вход и секреты развёртывания

Статус: `planned`. Приоритет определяется зависимостями, а не номером.

Зависимости: [DEC-011](DEC-011.md), [OPS-074](OPS-074.md), [OPS-013](OPS-013.md), [OPS-072](OPS-072.md)

## Модель для сессии

- Модель: `gpt-6.1-sol`.
- Уровень размышления: `high`.
- Обоснование: Безопасная граница HTTP и доверенного proxy без ослабления аутентификации.

Рекомендация, не переключение модели. [Условия выбора](../MODELS.md).

## Один результат

Публичный deployment-профиль с HTTPS для API/webhook и закрытой внутренней сетью.

## Критерии приёмки

- Оформить TLS termination, redirect HTTP→HTTPS, renewal сертификата, body/time limits и webhook URL. Публично доступны только необходимые REST/webhook routes; БД, Kafka, gRPC и служебные endpoints закрыты извне.
- Зафиксировать trusted proxy и источник IP для существующего auth rate limiter: клиент не подделывает адрес заголовком, а все пользователи не превращаются в один IP прокси. Проверить два адреса и поддельный forwarding header; при изменении контракта обновить OPS-013 ADR.
- Описать provisioning и замену bot token, webhook secret, DSN и mTLS cert/key с правами файлов и понятным restart/renewal. Не использовать публично тестовый CA/общий ключ.
- Небольшая проверка TLS, закрытых портов, protected routes и неверного webhook secret через реальный ingress на локальном fixture. Финальная проверка домена — E2E-006; deployment на чужой сервер и регистрация webhook требуют его данных и отдельного разрешения.

## Проверка

Только относящиеся к изменению unit/integration проверки, один небольшой smoke
на имеющихся средствах и обязательные проверки CI. Для поведения Red → Green;
для deployment/docs — проверка команд и фактического запуска, без искусственных
unit-тестов. Отсутствующую предпосылку не разрабатывать скрытно.

## Границы и сессионная проверка

Один ingress и секреты. Новая IAM-система, Kubernetes, WAF и полноценный pentest не входят.

Перед ready сверить фактические интерфейсы и размер по [workflow](../workflow.md).
При независимых результатах разделить; новая рекомендация модели объём не заменяет.
