# E2E-007 — Проверить восстановление малого рабочего стенда

Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [DEC-011](DEC-011.md), [OPS-074](OPS-074.md), [NTF-018](NTF-018.md), [SUB-024](SUB-024.md), [OPS-067](OPS-067.md)

## Модель для сессии

- Модель: `gpt-6.1-sol`.
- Уровень размышления: `high`.
- Обоснование: Малый smoke сохраняет проверку durable восстановления без нагрузки.

Рекомендация, не переключение модели. [Условия выбора](../MODELS.md).

## Один результат

Короткая проверка восстановления после рестарта Kafka, matcher и notifications на нескольких подписках.

## Критерии приёмки

- Использовать готовый стенд и fake Binance/Telegram, несколько подписок и обычную скорость. По одному ограниченному сценарию: временно недоступна Kafka; аварийно остановлен matcher; остановлен notifications с pending job/report.
- После возврата компонентов принятая работа продолжается, текущая цена проверяется, отменённая подписка не отправляется, SQL подтверждённый успех не переотправляется. Неоднозначный внешний timeout допускает документированный дубль по DEC-004.
- Сохранить команды и наблюдаемые ID/состояния, bounded deadline и cleanup своих ресурсов. Это функциональный restart smoke, без p99, миллионных данных, burst и сравнения реплик.
- Использовать имеющиеся process/E2E fixtures. Если нужной границы остановки нет, уточнить узкий недостающий шаг перед ready; новый универсальный chaos harness сюда не входит.

## Проверка

Только относящиеся к изменению unit/integration проверки, один небольшой smoke
на имеющихся средствах и обязательные проверки CI. Для поведения Red → Green;
для deployment/docs — проверка команд и фактического запуска, без искусственных
unit-тестов. Отсутствующую предпосылку не разрабатывать скрытно.

## Границы и сессионная проверка

Заменяет полезную часть отменённых LOAD-006/007/008. Backup/restore — OPS-076, реальный Telegram — E2E-006.

Перед ready сверить фактические интерфейсы и размер по [workflow](../workflow.md).
При независимых результатах разделить; новая рекомендация модели объём не заменяет.
