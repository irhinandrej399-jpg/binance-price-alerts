## Один результат

Закрытый classifier операций и raw reducer доказанных границ одновременного apparent size в поддержанном профиле.

## Критерии приёмки

- Для envelope OPS-034 задать полный classifier syscall/операций: доказанно нейтральные, наблюдаемые мутации и явно блокирующие. Default не считается нейтральным. Записать аргументы и returns, нужные для проверки классификации; альтернативные write/truncate/fallocate/copy, mmap/AIO/io_uring не пропускать как нулевые.
- Доказать порядок/границы для конкурентных grow/shrink/free, включая возможные промежуточные размеры внутри syscall и последнее освобождение reference. Указать шкалу/точность часов и влияние сериализации. Если ptrace механизм не даёт доказательства, оставить профиль неподдержанным и записать точную недостающую предпосылку вместо measured.
- Reducer из raw восстанавливает cluster apparent lower/upper; exact peak только при доказанной полноте и равенстве границ. Несовпадение, неизвестная операция/потеря/неполное окно дают peak=null, unknown/unsupported и qualification blocked. Не подменять границы суммой индивидуальных максимумов или snapshot maxima.
- Контролируемые независимые concurrent FS grow/shrink/close опыты проверяют ожидаемые интервалы и bounds; negative replay выявляет пропущенную мутацию, неизвестный syscall, неверные clocks/границы и подмену свидетельств даже с пересчитанными hashes. Артефакты/cleanup сохранены.
- Определить raw/report контракт и границы start/begin/end/finish для готовой модели OPS-036; apparent bytes отделены от allocated/device IO, cumulative counters и SQL temp relations.

## Проверка

raw replay и отказные случаи; инфраструктурные проверки без искусственных
unit-тестов наличия файлов. Сохранить воспроизведение и фактические результаты.
