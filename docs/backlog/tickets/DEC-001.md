# DEC-001 — Определить точную семантику достижения цены

Статус: `decision`. Приоритет определяется зависимостями, а не номером.

Зависимости: Нет.

## Модель для сессии

- Модель: `gpt-6.1-sol` (GPT-6.1 Sol).
- Уровень размышления: `medium` (Medium).
- Обоснование: Нужно уточнить один ценовой предикат и проверить граничные примеры; большой протокол здесь не проектируется.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Контракт одного предиката срабатывания.

## Критерии приёмки

- Зафиксированы направление, равенство порогу и поведение при уже выполненном условии на создании.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Проверка решения

Примеры: 99→100 при пороге 100; 101→100 вниз; цена уже равна порогу; скачок через порог.

Тип: решение, исполняемых тестов не требуется. Решение записать в `docs/decisions/` и обновить требования и зависимые карточки.

## Не входит

Повторяющиеся подписки.

## Размер сессии

Оценка: **кандидат на одну сессию после закрытия зависимостей**, не подтверждённый `ready`.
Для старта нужны только эта карточка, применимые ADR, готовые интерфейсы из зависимостей и относящийся к поведению код. Если требуется выбрать протокол, реализовать недостающую зависимость или менять независимое поведение, карточка сначала уточняется либо делится по [сессионной проверке](../workflow.md#сессионная-проверка-перед-ready).
