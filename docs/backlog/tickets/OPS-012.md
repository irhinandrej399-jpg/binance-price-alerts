Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [IAM-003](IAM-003.md), [IAM-004](IAM-004.md), [SUB-003](SUB-003.md)

Разделённый исходный тикет: [OPS-005](OPS-005.md).

## Модель для сессии

- Модель: `gpt-6-luna` (GPT-6 Luna).
- Уровень размышления: `high` (High).
- Обоснование: Один middleware размера тела имеет ясную границу и конечный набор HTTP-проверок, включая chunked запрос.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Один middleware предела тела на публичном API.

## Критерии приёмки

- Превышение даёт стабильную ошибку до тяжёлой обработки; допустимое тело читается корректно.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Сценарии TDD (Red → Green → Refactor)

HTTP-тесты непосредственно до, на и после предела, а также chunked-body.

## Не входит

Rate limiting и сетевой DDoS.

## Размер сессии

Оценка: **кандидат на одну сессию после закрытия зависимостей**, не подтверждённый `ready`.
Для старта нужны только эта карточка, применимые ADR, готовые интерфейсы из зависимостей и относящийся к поведению код. Если требуется выбрать протокол, реализовать недостающую зависимость или менять независимое поведение, карточка сначала уточняется либо делится по [сессионной проверке](../workflow.md#сессионная-проверка-перед-ready).

## Контракт и сессионная проверка

- 6 ноября 2026: next/show выбрали OPS-012. Зависимости IAM-003/IAM-004/SUB-003 подтверждены карточками и готовыми registration/login/subscription handlers; HTTP JSON-контракт следует DEC-009. Рабочих tracked-изменений на входе нет; посторонние untracked исследования сохранены. Рекомендация Luna/high сообщена; настройки модели не менялись. Сессионная проверка пройдена, planned → ready → in-progress.
- Один результат — middleware `bodylimit.New(maxBytes, next)`, с текущим эксплуатационным бюджетом публичного API 65536 байт включительно. Конструктор принимает положительный предел и handler. Это предел wire body без декомпрессии, общий для методов и Content-Type; rate limit/параллелизм не входят.
- Content-Length выше предела отклоняется до чтения. Иначе полное ограниченное чтение, включая chunked, завершается до auth/JSON/SQL/RPC/Argon2id. Превышение — 413 `request_body_too_large`, другая ошибка чтения — 400 `invalid_request`, единый JSON error/code, no-store. Допустимые байты и request context сохраняются. Сервер задаёт ReadTimeout.

## Ход работы

- Добавлены `internal/api/bodylimit/bodylimit.go`, HTTP-тесты и README. В `cmd/api/main.go` middleware оборачивает весь публичный mux до auth, обновлён README процесса. При будущем монтировании registration/login/create они получат тот же предел; самостоятельно собирать полный API в OPS-012 не требуется.
- Red: `GOTOOLCHAIN=local GOCACHE=/tmp/binance-go-build go test ./internal/api/bodylimit` — exit 1, `no non-test Go files`: middleware отсутствовал.
- Green: после реализации та же команда в sandbox остановилась на запрете loopback listener (это не ошибка поведения). Повтор с разрешённым доступом — PASS, exit 0. Настоящие HTTP-запросы с Content-Length и chunked: пустое тело, 31/32/33/1024 байта при пределе 32; допустимые байты неизменны, при превышении handler не вызван, стабильны status/body/headers.
- Дополнительные сценарии: заявленный oversize не читает источник; read error не вызывает handler и не раскрывает текст ошибки, закрывает body; бесконечный источник неизвестной длины читается ровно до limit + 1 байта и получает 413. Refactor: общий reject, стандартный MaxBytesReader и воспроизведение bytes.Reader, без изменений прикладных декодеров и SQL.
- Итог: `GOTOOLCHAIN=local GOCACHE=/tmp/binance-go-build go test -race -count=1 ./...` с loopback-доступом — PASS, exit 0, включая новые сценарии. PostgreSQL/Kafka/process opt-in тесты в этом прогоне пропущены; новые проверки используют настоящий HTTP без БД. SQL/relay-поведение не менялось.
- `GOTOOLCHAIN=local GOCACHE=/tmp/binance-go-build go vet ./...` — PASS. Сборка в sandbox вернула exit 0 с предупреждением stat cache; итоговый `GOTOOLCHAIN=local GOCACHE=/tmp/binance-go-build go build ./...` с доступом к module cache — PASS без предупреждений.
- `git diff --check` и `python3 scripts/backlog.py check` — PASS. Критерии выполнены, статус done. Посторонние untracked исследования не включаются в коммит.
