# SET-004 — Добавить запуск миграций

Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [SET-001](SET-001.md), [SET-003](SET-003.md)

## Модель для сессии

- Модель: `gpt-6.1-sol` (GPT-6.1 Sol).
- Уровень размышления: `medium` (Medium).
- Обоснование: Нужно проверить повторный запуск миграций и ошибку применения на реальной временной БД.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Одна команда применения версионированных миграций.

## Критерии приёмки

- По [DEC-006](../../decisions/DEC-006.md): история и блокировка миграций раздельны для каждой БД владельца; runtime не мигрирует схему. Повтор безопасен, изменение применённого файла обнаруживается; ошибка транзакционного DDL откатывает схему и историю вместе. Проверить повтор, ошибку и двух конкурентных исполнителей на реальном PostgreSQL.

- Повторный запуск безопасен; ошибка миграции видна вызывающему процессу.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Проверка / воспроизведение

На пустой временной БД выполнить тестовую миграцию дважды и проверить обработку некорректной миграции.

## Не входит

Рабочие схемы всех сервисов.
