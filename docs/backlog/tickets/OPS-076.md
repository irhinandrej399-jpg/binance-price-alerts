# OPS-076 — Подготовить резервную копию и восстановление стенда

Статус: `planned`. Приоритет определяется зависимостями, а не номером.

Зависимости: [DEC-011](DEC-011.md), [OPS-074](OPS-074.md), [OPS-014](OPS-014.md)

## Модель для сессии

- Модель: `gpt-6.1-sol`.
- Уровень размышления: `high`.
- Обоснование: Восстановление согласованного состояния SQL/Kafka/cleaner важнее формального наличия backup.

Рекомендация, не переключение модели. [Условия выбора](../MODELS.md).

## Один результат

Один рабочий runbook и команды согласованного cold backup/restore с проверкой на изолированной копии.

## Критерии приёмки

- Выбрать простой backup с явно указанным downtime: остановить writers и cleaner, согласованно сохранить четыре БД, Kafka с topic identities/offsets и cleaner registry/deletion floors. Не объявлять несогласованный набор независимых live dumps восстанавливаемым backup.
- Зафиксировать состав, версии, права и защиту копии/ключей, место вне основного диска, срок хранения, команды расписания и проверку неуспеха. Секреты не включать в публичные артефакты.
- Восстановить малый стенд в отдельные volumes: login, pending подписка, проекция и доставка продолжаются; подтверждённый результат не переотправляется. Совпадение SQL checkpoints с Kafka source проверяется, ошибочное смешивание копий отвергается.
- Зафиксировать фактические время/объём и ручные шаги. Тесты через существующие fixtures; реальный bot в восстановленной копии не использовать. Потерю всего хоста не называть HA.

## Проверка

Только относящиеся к изменению unit/integration проверки, один небольшой smoke
на имеющихся средствах и обязательные проверки CI. Для поведения Red → Green;
для deployment/docs — проверка команд и фактического запуска, без искусственных
unit-тестов. Отсутствующую предпосылку не разрабатывать скрытно.

## Границы и сессионная проверка

Один cold backup/restore профиль; PITR, zero downtime и межрегиональная репликация не входят.

Перед ready сверить фактические интерфейсы и размер по [workflow](../workflow.md).
При независимых результатах разделить; новая рекомендация модели объём не заменяет.
