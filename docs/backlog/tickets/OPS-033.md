# OPS-033 — Сохранять и проверять передачу FD через ancillary data

Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [OPS-019](OPS-019.md)

Выделен из [OPS-031](OPS-031.md) 5 ноября 2026 при проверке размера сессии.

## Модель для сессии

- Модель: `gpt-6.1-sol`.
- Уровень размышления: `high` (High).
- Обоснование: Чтение памяти tracee, ABI и truncation требуют проверки реальными передачами FD и отказами.

Это рекомендация, а не переключение модели. [Условия выбора](../MODELS.md).

## Один результат

Raw capture/replay sendmsg/recvmsg и их многосообщенческих вариантов с проверяемыми SCM_RIGHTS свидетельствами.

## Критерии приёмки

- Определить версионированный raw-контракт Linux arm64 для msghdr/cmsghdr: входная ёмкость и выходная длина, flags, контрольные bytes и возвращённые FD. Учесть sendmsg/recvmsg/sendmmsg/recvmmsg, частичный успех, MSG_CTRUNC, ошибки чтения памяти и рестарт syscall.
- Переданный FD сопоставлять с независимыми dev/inode/size/nlink; хранить достаточные свидетельства отправителя/получателя. Передача или недекодированная ancillary data не может молча считаться отсутствием ссылок. Ссылки в очереди сокета явно передаются как нерешённое обязательство OPS-034.
- На disposable Linux ФС проверить реальную передачу обычного и unlink-open work FD, несколько FD, отсутствие control data, truncated buffer и отказ syscall. Replay отвергает удалённые/подменённые обязательные свидетельства, включая случай после пересчёта hashes.
- Повторить ordinary/parallel PG capture и показать декодирование всех встреченных message syscalls; старый gate-g не менять. Сохранить команды, ABI/версии, hashes и cleanup.
- Этот результат не объявляет полноту observer: peak/lower/upper остаются null, qualification blocked. Документировать интерфейс событий для OPS-034.

## Проверка

Реальные disposable Linux filesystem/PostgreSQL контроли по критериям выше,
raw replay и отказные случаи; инфраструктурные проверки без искусственных
unit-тестов наличия файлов. Сохранить воспроизведение и фактические результаты.

## Не входит

Модель всей истории inode/сокетных очередей, полный syscall classifier, численные границы и интерфейс фаз.

## Сессионная проверка

До ready проверить готовность зависимости, контракт и средства проверки.
Неподтверждённая предпосылка оставляет planned; чужой механизм не выполнять
скрытно. Критерии контейнера не ослабляются при ограничении поддержанного профиля.
