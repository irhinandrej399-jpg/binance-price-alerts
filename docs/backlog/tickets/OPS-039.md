# OPS-039 — Сохранять lifecycle evidence при shared state и nonleader exec

Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [OPS-038](OPS-038.md)

Выделен из [OPS-037](OPS-037.md) после реального preflight 5 ноября 2026.

## Модель для сессии

- Модель: `gpt-6.1-sol`.
- Уровень размышления: `high` (High).
- Обоснование: TID transition при exec, shared FD tables/memory и ptrace stop ordering требуют согласованного lifecycle journal.

Это рекомендация, а не переключение модели. [Условия выбора](../MODELS.md).

## Один результат

Raw lifecycle journal, не теряющий родство, аргументы и незавершённые операции
при fork/clone/clone3, shared state, exec из другого thread и exit.

## Критерии приёмки

- На inventory-контракте OPS-038 сохранять операции/аргументы/returns для
  reopen/dup/fcntl, fork/clone/clone3/exec/exit. Сохранять pointed-to данные,
  нужные для flags/path/identity replay; clone3 flags не выводить из адреса.
  Чтение с ошибкой, неизвестный ABI/размер структуры или необработанное событие
  дают incomplete, а не потерю события.
- Исправить/проверить обработку PTRACE_EVENT_EXEC из другого thread: бывший TID,
  новая идентичность leader, pending syscall, исчезнувшие siblings и состояние
  gate/очереди не остаются молча привязаны к прежнему TID. Воспроизвести timeout
  preflight OPS-037, проверить завершение и независимые PID/TID/starttime.
  Причину текущего timeout установить по дополнительным stop witnesses;
  первоначальный partial raw не доказывает конкретный deadlock.
- Сопоставлять lifecycle с независимым census OPS-038, включая ранний child stop,
  inherited return, exec/exit и shared FD table/VM flags. При расхождении,
  потерянном процессе или несогласованном shared-state чтении явно блокировать.
  Не подменять это lifetime/last-reference моделью.
- Реальные Linux controls: наследование FD, dup/fcntl, shared FD table/memory,
  exec/exit и nonleader exec. Проверить поддержанный clone3 и отказный путь
  (если kernel запрещает clone3, не объявлять успешное создание проверенным).
  Независимый helper подтверждает фактические flags/переходы, не только журнал.
- Полный lifecycle verifier на rehashed/resequenced артефактах отвергает либо
  помечает incomplete пропуск/подмену flags, родства, exec transition и returns.
  Сохранить команды/source/binary/raw hashes, cleanup и контракт OPS-040.
  Peak/lower/upper=null, qualification blocked.

## Проверка

Реальные disposable Linux process/FD controls, census и raw replay/tamper.

## Не входит

Разработка inventory capture заново, модель поколений/last reference OPS-034,
queue-only reference fixture и итоговый PG capture/verifier OPS-040,
size classifier, интеграция фаз.

ptrace scheduler. Не заменять эту предпосылку разработкой нового census.
