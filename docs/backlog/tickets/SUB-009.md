## Один результат

## Критерии приёмки

- По [DEC-007](../../decisions/DEC-007.md): delivery-requests, ключ subscription_id, устойчивые event_id/trigger_id; стабильный transactional.id и fencing relay. SQL-отметка только после подтверждённого commit Kafka; транзакция PostgreSQL и Kafka не объявляется общей. Используется готовый подход SUB-007.

- Неподтверждённые события не теряются; повтор сохраняет trigger_id.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).
