# MKT-015 — Построить план уникальных рыночных потоков

Статус: `done`. Приоритет определяется зависимостями, а не номером.

Зависимости: [MKT-001](MKT-001.md)

Разделённый исходный тикет: [MKT-008](MKT-008.md).

## Модель для сессии

- Модель: `gpt-6-luna` (GPT-6 Luna).
- Уровень размышления: `high` (High).
- Обоснование: Чистая функция дедупликации и разбиения каталога по лимиту соединений проверяется небольшими табличными примерами.

Это рекомендация для выбора перед запуском, а не автоматическая смена модели. [Условия выбора и повышения уровня](../MODELS.md).

## Один результат

Чистая функция каталог→группы уникальных потоков по лимиту соединения.

## Критерии приёмки

- Одна пара присутствует один раз; в группе не превышен лимит; порядок плана детерминирован.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Сценарии TDD (Red → Green → Refactor)

Пустой каталог, дубль, ровно лимит и лимит+1 дают ожидаемые группы.

## Не входит

Открытие соединений и обновление действующего каталога.

## Размер сессии

Оценка: **кандидат на одну сессию после закрытия зависимостей**, не подтверждённый `ready`.
Для старта нужны только эта карточка, применимые ADR, готовые интерфейсы из зависимостей и относящийся к поведению код. Если требуется выбрать протокол, реализовать недостающую зависимость или менять независимое поведение, карточка сначала уточняется либо делится по [сессионной проверке](../workflow.md#сессионная-проверка-перед-ready).
