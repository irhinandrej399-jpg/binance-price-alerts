# SUB-015 — Прочитать согласованный снимок из хранилища

Статус: `planned`. Приоритет определяется зависимостями, а не номером.

Зависимости: [SUB-001](SUB-001.md), [SUB-011](SUB-011.md), [SUB-012](SUB-012.md), [DEC-004](DEC-004.md)

Разделённый исходный тикет: [SUB-010](SUB-010.md).

## Один результат

Один storage-интерфейс страниц снимка и границы replay по готовому протоколу DEC-004.

## Критерии приёмки

- Страницы относятся к одной логической границе; cursor имеет определённую связь с потоком; срок жизни ресурсов следует DEC-004.
- Выполнена указанная ниже проверка; соблюдены [общие критерии готовности](../workflow.md).

## Сценарии TDD (Red → Green → Refactor)

Изменение записи между двумя страницами не даёт смешанного снимка; проверены повтор страницы и истечение срока по контракту.

## Не входит

Сетевой endpoint и локальная проекция matcher; изобретение протокола внутри реализации.

## Размер сессии

Оценка: **кандидат на одну сессию после закрытия зависимостей**, не подтверждённый `ready`.
Для старта нужны только эта карточка, применимые ADR, готовые интерфейсы из зависимостей и относящийся к поведению код. Если требуется выбрать протокол, реализовать недостающую зависимость или менять независимое поведение, карточка сначала уточняется либо делится по [сессионной проверке](../workflow.md#сессионная-проверка-перед-ready).
