После удаления временных файлов все три run-шага на фактическом репозитории также exit 0; четыре пакета сообщают `[no test files]`. Использованы Go 1.26.3 darwin/arm64, GOCACHE=/tmp/binance-set-002-go-build, GOPATH=/tmp/binance-set-002-gopath, GOPROXY=off, GOSUMDB=off.
