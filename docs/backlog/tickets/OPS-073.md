## Один результат

Готовые POST/GET /v1/subscriptions доступны в настоящем API с удалёнными Catalog/Latest.

## Критерии приёмки

- POST и GET смонтированы с session/auth рядом с существующим DELETE. Используются subscription.NewHandler/NewListHandler; владелец не берётся из входных user_id.
- Catalog и Latest используют управляемые mTLS clients API с явными адресами/DNS/credentials; политику/ошибки/предупреждения готовых handlers не менять. Connections закрываются общим lifecycle.
- Создание фиксирует quota/subscription/journal/outbox атомарно; HTTP body limit, auth quota и shutdown существующего API сохраняются. Исправлена устаревшая таблица маршрутов cmd/api/README.md.

- Выполнены проверки ниже и [общие критерии готовности](../workflow.md).
