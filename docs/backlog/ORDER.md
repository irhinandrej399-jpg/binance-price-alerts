# Очередь выполнения тикетов

Это единый последовательный маршрут для работы одного агента. Строки ниже идут от ранних задач к поздним; все зависимости находятся выше своих потребителей. Каталог README.md остаётся сгруппированным по областям.

По умолчанию брать первую незавершённую карточку, предварительно продолжив уже начатую работу. `done` пропускается; `decision` означает обсуждение решения; `planned` требует проверки перед ready. Контейнеры `split` в очередь не входят.

Команда `python3 scripts/backlog.py next` использует именно этот файл. `next --limit 5` показывает пять ближайших незавершённых пунктов как предварительный просмотр, а не пять разрешённых одновременно задач. `python3 scripts/backlog.py check` проверяет полноту очереди и расположение зависимостей.

Если ADR изменил архитектуру или карточку разделили, обновить карточки, индекс и эту очередь в том же изменении. Новые дочерние задачи поставить на место контейнера с учётом зависимостей. Порядок не отменяет прямое поручение пользователя, но агент самостоятельно его не перескакивает.
