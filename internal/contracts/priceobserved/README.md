# PriceObserved — CON-003

`priceobserved.Observed` — одна принятая корректная котировка. Конверт
[CON-001](../event/README.md): `type=price.observed`, `version=1`,
`ordering_key=pair`. `Encode`/`Decode` проверяют метаданные и payload;
`Validate` и JSON-методы проверяют сам payload. ID не генерируются.

```json
{
  "schema_version": 1,
  "pair": "BTCUSDT",
  "price": "123.456789012345678901",
  "source_id": "9007199254740993",
  "revision": {
    "stream_id": "binance-spot-trade",
    "generation": 2,
    "sequence": 17
  },
  "trade_time": "2026-10-27T10:00:00.123456Z",
  "received_at": "2026-10-27T10:00:01.123456Z",
  "source_event_time": "2026-10-27T10:00:00.123457Z",
  "stream_state": "unconfirmed",
  "gap_detected": true
}
```

| Поле | Контракт |
| --- | --- |
| `schema_version` | Обязательное целое 1; неизвестная/отсутствующая версия — `ErrUnsupportedVersion`. |
| `pair` | Непустая нормализованная пара, только ASCII A–Z/0–9. Наличие в каталоге проверяет market-data. |
| `price` | Обязательная положительная точная JSON-строка доменного Price: до 18 целых и 18 дробных цифр, без float. |
| `source_id` | Непустой непробельный непрозрачный ID исходной сделки/агрегата, строка для сохранения точности. Область уникальности — источник/вид потока и пара; не заменяет event_id или ревизию. Выбор trade/aggTrade остаётся MKT-002. |
| `revision.stream_id` | Непустая стабильная идентичность логического источника/вида потока. Не ID WebSocket-соединения. |
| `revision.generation` | Положительный uint64, монотонное durable поколение пары внутри stream_id. |
| `revision.sequence` | Положительный uint64, монотонный номер принятой цены внутри поколения. |
| `trade_time` | Обязательное ненулевое RFC3339-время сделки, Binance T. |
| `received_at` | Обязательное ненулевое RFC3339-время первоначального приёма приложением. Не обновляется при replay/relay. |
| `source_event_time` | Необязательное время Binance E; отсутствие/null допустимы. Если передано, ненулевое RFC3339-время. Не подменяет T. |
| `stream_state` | Обязательное `unconfirmed` или `live`, состояние на момент наблюдения. Возраст сделки не определяет это поле. |
| `gap_detected` | Обязательный boolean: известен исторический пропуск в текущем логическом потоке пары. Отсутствие/null запрещены; false — явное значение. |

## Порядок и повтор

`NewerThan` сравнивает `(generation, sequence)` лексикографически только для
одинаковых pair и stream_id. Более старое поколение проигрывает даже при большем
sequence; равная ревизия — повтор, обновления последней цены нет. Времена, source ID,
Kafka offset и cursor C журнала подписок в этом сравнении не участвуют.
Разные пары/stream_id дают `ErrIncomparableRevision`: произвольные строки нельзя
упорядочивать как поколения. Смена вида источника требует явной миграции состояния
потребителя, а не сброса счётчика под новым stream_id.

Market-data обязан сохранять поколение/номер вместе с последней котировкой и
outbox, увеличивать ревизию, не переиспользовать её для другой цены. При сбросе
sequence сначала durable увеличивается generation; переполнение требует остановки,
а не wraparound. Reconnect может продолжить сохранённую шкалу. Повтор публикации
сохраняет всю ревизию, source ID, времена и event_id. JSON uint64 декодируются
точно в Go; другие потребители обязаны использовать целочисленный lossless parser.
Пакет даёт правило сравнения, но не реализует хранилище и не может проверить
монотонность отдельно взятого сообщения. Применение без отката — MKT-005/MAT-012;
равная ревизия с другим содержимым является повреждением, а не новой ценой.

## Времена

`NormalizeTimestamp(value, Milliseconds|Microseconds)` переводит исходные T и E
в UTC, не используя float или умножение всей Unix-метки на наносекунды.
Микросекунды сохраняются полностью. Единицы указываются явно конфигурацией адаптера,
по величине числа не угадываются. Неподдерживаемые единицы, нулевое Go-время и годы
вне 1…9999 отклоняются. Wire — RFC3339 с точностью до наносекунд; допустимые часовые
пояса сохраняют момент времени. Время конверта — исходное время логического события,
не замена времени сделки. Поздний приём и replay не омолаживают T.

Проверки возраста/будущего относительно подставляемых часов выполняются при
использовании котировки по DEC-002/DOM-005. Схема проверяет представимость времён,
не вводит ограничения максимального возраста или скрытого допуска clock skew.

## Разрыв

Запуск/рестарт и известная потеря связи означают `unconfirmed`. Reconnect сам по
себе не переводит поток в `live`. Критерий подтверждения актуального приёма должен
быть реализован владельцем потока; этот пакет не делает сетевых наблюдений.
После обнаруженного пропуска `gap_detected=true` сохраняется и при возвращении
`live`, и при смене поколения того же логического потока: исторические сделки
не восстановлены. `false` не гарантирует отсутствия неизвестных пропусков.

Payload фиксирует состояние при наблюдении цены. Он не является уведомлением
о disconnect, возникшем после последней сделки: актуальное состояние отсутствующего
потока обязан отдельно хранить/выдавать market-data (MKT-006). Ради обозначения
разрыва нельзя создавать фиктивную новую сделку или менять T сохранённой цены.
Новая цена с gap не обещает пересечения внутри отсутствовавших данных.

## Ошибки и границы

Повреждённый payload — `ErrInvalidObservation`, неизвестная версия —
`ErrUnsupportedVersion`; ошибки различаются через `errors.Is`. Неуспешный
UnmarshalJSON не меняет получатель. Неизвестные дополнительные поля допускаются;
их сохранение при повторной сериализации не гарантируется. Повреждение/неизвестная
версия не разрешают молчаливый skip/ack (DEC-007).

Проверка: `GOTOOLCHAIN=local go test ./internal/contracts/priceobserved`.
WebSocket, выбор исходных сделок, durable счётчики, outbox и matcher не реализованы.
