# Предел тела публичного API (OPS-012)

`bodylimit.New(maxBytes, next)` — HTTP middleware; положительный предел в байтах,
ненулевой handler, ошибочная конфигурация вызывает panic при сборке маршрутов.
`PublicLimit` — текущий эксплуатационный бюджет 64 КиБ (65536 байт).
Предел включительный, применяется к любому методу и Content-Type.

Подключать один раз снаружи публичного mux, перед auth, JSON, Argon2id, SQL и RPC:

```go
handler := bodylimit.New(bodylimit.PublicLimit, mux)
```

В `cmd/api` уже подключён ко всему HTTP mux. Регистрация, вход и создание
подписки пока доступны как компоненты; при их будущем монтировании они получат
тот же предел. При отдельном использовании их handlers также нужно обернуть.

Заявленный Content-Length выше предела отклоняется без чтения приложением.
Иначе middleware читает тело целиком через MaxBytesReader, включая chunked
и неизвестную длину. Чтение ограничено limit + 1 байтами; до успешного EOF
следующий handler не вызывается. Допустимое тело воспроизводится без изменения
байтов, context и заголовков. Это буферизация одного ограниченного тела;
общий объём памяти зависит также от числа одновременных запросов.

Превышение: HTTP 413, JSON `{"error":{"code":"request_body_too_large"}}`.
Другая ошибка чтения: HTTP 400, `{"error":{"code":"invalid_request"}}`.
Оба ответа имеют Content-Type application/json и Cache-Control no-store,
без входных данных и текста внутренних ошибок. Даже при недоступной сессии
слишком большое тело получает 413 раньше проверки credentials.

HTTP server обязан задавать конечный ReadTimeout (в cmd/api — 10 с).
Middleware ограничивает байты тела после HTTP transfer framing; декомпрессия
не выполняется. Rate limiting, лимиты параллелизма, заголовков и защита от DDoS
не входят в этот компонент.

Проверка: `GOCACHE=/tmp/binance-go-build go test -race ./internal/api/bodylimit`.
Тесты используют настоящий HTTP loopback для обычного и chunked тела на
границах 31/32/33 байта, пустого и сильно превышающего тела; дополнительно
проверяют отказ до чтения, bounded read и ошибку источника.
