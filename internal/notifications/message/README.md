# Текст уведомления: NTF-002

`Format(Input) (string, error)` — чистая функция одного сообщения на русском.
Отправитель должен передать результат как `text` с `parse_mode=HTML`.
`&`, `<`, `>` в отображаемой паре экранируются один раз; остальные символы
остаются текстом. Нормализация символа пары принадлежит входному контракту,
formatter принимает отображаемую строку. Вызов Telegram и локализация отдельно.
Правила HTML сверены 30 октября 2026 с
[Telegram Bot API](https://core.telegram.org/bots/api#html-style).

Поля `Pair`, `Threshold`, `Direction` берутся из подписки. `ActualPrice`,
`TradeTime`, `StreamUnconfirmed`, `GapDetected` — **из проверенной котировки
допуска текущей попытки API**, а не `AlertTriggered.CandidateQuote`.
Для `AttemptPermission.Quote` это `price`, `trade_time`,
`stream_state == unconfirmed`, `gap_detected`. Транспортные строки предварительно
парсятся в точные `price.Price` и `time.Time`; никакого float/округления.
`CheckedAt` передаётся из часов caller при формировании текста. Историческое
событие целиком в интерфейс форматирования не передаётся.

Текст содержит пару, включительное направление вверх/вниз, фиксированный порог,
фактическую цену, время сделки UTC и точный возраст в секундах. Возраст > 5 секунд
даёт предупреждение DEC-002 без отказа; unconfirmed или gap дают отдельное
предупреждение даже при молодой цене. При обоих признаках оно выводится один раз.
Время сделки не подменяется временем получения/чтения. Отсутствующее/будущее
время, неверное время проверки, нулевая фактическая цена, пустая пара и неизвестное
направление дают `ErrInvalidInput` и пустой текст. Нулевой порог допустим.

Функция не подтверждает полномочия, срок допуска или выполнение условия.
Caller отправляет только при действующем допуске после лимитеров и без нового
ожидания. После задержки/рестарта требуется новый допуск по DEC-004. Старая
корректная цена не становится TTL задания; предупреждения не обещают возможность
сделки к прочтению сообщения. Worker, сетевые адаптеры и runtime сюда не входят.

Проверка: `GOTOOLCHAIN=local go test -race ./internal/notifications/message -count=1`.
Fixtures проверяют оба направления, диапазон 18/18, нормализацию, HTML-символы,
границу 5 с + 1 нс, независимые предупреждения, UTC и возраст без переполнения
`time.Duration`.
